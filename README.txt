PANDUAN
1. Ekstrak ZIP dan buka folder ini di VS Code.
2. Jalankan index.html dengan Live Server.
3. Taruh foto di folder images. Didukung: foto (1).jpeg ... foto (48).jpeg atau foto1.jpg ... foto48.jpg. Script mencoba jpeg/jpg/png/webp.
4. Tanggal hitung ada di script.js pada ANNIVERSARY_DATE. Ubah jika perlu.
5. Tiap halaman sudah punya tombol Kembali/Lanjut dan memakai style.css serta script.js yang sama.
6. Jika ingin musik, tambahkan file music.mp3 dan elemen audio/tombol sesuai README sebelumnya; musik belum diaktifkan otomatis di template ini.
